========================================
  COMPACTADOR DE ARQUIVOS
========================================

Como usar:
----------
1. Dê dois cliques em "Compactador.exe"
2. Clique em "Procurar" e selecione a pasta com os arquivos
3. Escolha o modo:
   [ ] desmarcado → cria um .zip por arquivo
                    ex: video01.mp4 → video01.zip
                        video02.mp4 → video02.zip

   [x] marcado    → compacta tudo em um único ZIP
                    ex: pasta.zip com todos os arquivos dentro

4. Clique em "COMPACTAR TUDO"
5. Aguarde o progresso. Ao finalizar o programa reseta
   automaticamente para você compactar outra pasta.

Opções extras:
--------------
- Incluir subpastas: processa arquivos dentro de subpastas também
- Apagar original:   remove o arquivo original após compactar
                     (use com cuidado!)

Não precisa instalar nada. Só o .exe já funciona.
